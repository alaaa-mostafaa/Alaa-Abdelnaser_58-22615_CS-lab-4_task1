The original dataset contained **39 rows** and several inconsistencies in the `faculty`, `club`, `city`, `full_name`, `email`, `fee_paid`, and `signed_up_at` columns. I first inspected the dataset shape, data types, and categorical value counts to identify the problems. Faculty, club, and city values were standardized by stripping spaces, converting text to lowercase, and mapping the different variants to their required canonical values. Names were cleaned by removing extra spaces and applying consistent capitalization, while emails were stripped and converted to lowercase. Different `fee_paid` representations were converted into Boolean values, and the two date formats in `signed_up_at` were parsed into one datetime column. I first removed **3 exact duplicate rows**, reducing the dataset from **39 to 36 rows**. I then checked repeated sign-ups using `student_id` and `club`. Before standardizing club spellings, only **2** repeated sign-ups would have been detected, while after standardization **4** were detected, meaning **2 repeated sign-ups would have been missed** if club cleaning was not performed first. I kept the latest submission because it may contain updated information, especially the fee-payment status. Removing the **4 repeated sign-ups** left **32 final rows**. Duplicate detection used `student_id` and `club` rather than `full_name`, so two different students with the same name were not incorrectly merged.
